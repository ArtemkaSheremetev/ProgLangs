# Reg32 Compiler & Virtual Machine

Учебно-исследовательский проект компилятора и виртуальной машины для простой 32-битной Harvard-архитектуры.

Цель проекта — разобраться, как работает компилятор.

- Вариант грамматики: **2**
- Вариант ISA: **26**

---

## Общая идея

Проект включает:

- собственный язык высокого уровня (Pascal-like)
- компилятор на C++
- генерацию ассемблера под кастомную ISA
- виртуальную машину с регистрами и стеком
- поддержку рекурсии
- встроенные функции ввода/вывода

---

## Архитектура

### ISA / VM

- Harvard-архитектура
- 32-битные регистры
- 2-адресные инструкции
- стек вызовов (`sp`, `bp`)
- поддержка рекурсии
- ввод/вывод через `rin` / `rout`

---

## Сборка проекта

Из корня репозитория:

```bash
mkdir build
cd build
cmake ..
make
./ProgLang ../program.txt
```

Для просмотра графа потока управления (CFG) и деревьев операций выполните:
```bash
bash dot_to_png.sh
```
## Запуск и тестирование
В тестовой программе program.txt реализован калькулятор с поддержкой вычисления чисел Фибоначчи.

После генерации ассемблера выполните:
```bash
bash build_script.sh
bash execute_script.sh
```

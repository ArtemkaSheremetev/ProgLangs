# Reg32 Compiler & Virtual Machine

Учебно-исследовательский проект компилятора и виртуальной машины для простой 32-битной Harvard-архитектуры.

Цель проекта — разобраться, **как реально работает компилятор**, а не только парсер.

---

##Общая идея

Проект включает:

- собственный язык высокого уровня (Pascal-like)
- компилятор на C++
- генерацию ассемблера под кастомную ISA
- виртуальную машину с регистрами и стеком
- поддержку рекурсии
- встроенные функции ввода/вывода

---

## Архитектура

### ISA / VM

- Harvard-архитектура
- 32-битные регистры
- 2-адресные инструкции
- стек вызовов (`sp`, `bp`)
- рекурсия поддерживается
- ввод/вывод через `rin` / `rout`

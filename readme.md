# Reg32 Compiler & Virtual Machine

Учебно-исследовательский проект компилятора и виртуальной машины для простой 32-битной Harvard-архитектуры.

Цель проекта — разобраться, как работает компилятор

Вариант грамматики: 2
Вариант для написания ISA: регистровая архитектура(двухадрессная + code и mem банки)(гарвардская архитектура)
---

##Общая идея

Проект включает:

- собственный язык высокого уровня (Pascal-like)
- компилятор на C++
- генерацию ассемблера под кастомную ISA
- виртуальную машину с регистрами и стеком
- поддержку рекурсии
- встроенные функции ввода/вывода

---

## Архитектура

### ISA / VM

- Harvard-архитектура
- 32-битные регистры
- 2-адресные инструкции
- стек вызовов (`sp`, `bp`)
- рекурсия поддерживается
- ввод/вывод через `rin` / `rout`

### Сборка проекта

Из корня репозитория:

```bash
mkdir build
cd build
cmake ..
make
./ProgLang program.txt
```
Для желания посмотреть на граф потока управления и деревья операций:
```bash
dot_to_png.sh
```

В тестовой программе program.txt написан калькулятор с поддержкой вычисления чисел фибоначи.

После запуска исполняемого файла:

```bash
bash build_script.sh
bash execute_script.sh
```
